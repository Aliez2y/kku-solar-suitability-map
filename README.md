# ☀️ SolarSuit-KKU (Solar Suitability Web Map)

แอปพลิเคชันแผนที่บนเว็บ (Web Map Application) สำหรับแสดงผลการประเมินศักยภาพและระดับความเหมาะสมในการติดตั้งระบบผลิตไฟฟ้าพลังงานแสงอาทิตย์บนหลังคาอาคาร ในเขตเทศบาลนครขอนแก่น

โปรเจกต์นี้เป็นการนำข้อมูลที่ได้จากการวิเคราะห์เชิงพื้นที่ (Spatial Analysis) มาแสดงผลในรูปแบบ Interactive Web Map เพื่อให้ผู้ใช้งานสามารถดูภาพรวมและตรวจสอบศักยภาพของแต่ละอาคารได้โดยง่าย

## 🌍 แหล่งที่มาของข้อมูลและการวิเคราะห์ (Data Integration)
ข้อมูลทั้งหมดที่นำมาแสดงผลบนเว็บไซต์ ผ่านกระบวนการวิเคราะห์จากโปรแกรมภูมิสารสนเทศ (GIS) อย่าง **ArcGIS Pro** และ **QGIS** โดยแบ่งประเภทข้อมูลที่นำมาพัฒนาลงเว็บไซต์หลักๆ ดังนี้:

### 1. เลเยอร์แผนที่รังสีดวงอาทิตย์ (Tile Layers)
- **การวิเคราะห์**: เป็นภาพจำลองค่าความเข้มรังสีดวงอาทิตย์ที่ได้จากการวิเคราะห์การตกกระทบของแสงแดด (Solar Radiation Analysis) ผสมผสานกับการสร้างแบบจำลองความสูงภูมิประเทศและอาคาร (DSM) 
- **การแปลงข้อมูลลงเว็บ**: ไฟล์ผลลัพธ์ที่เป็นพื้นที่ภาพต่อเนื่อง (Raster) ถูกนำไปผ่านกระบวนการ Generate Map Tiles ในซอฟต์แวร์ GIS แปลงให้กลายเป็นภาพตารางสี่เหลี่ยมย่อยๆ ขนาด 256x256 px เพื่อให้สามารถดึงมาแสดงผลบนหน้าเว็บไซต์ได้อย่างรวดเร็ว แผนที่ย่อยทั้งหมดจะถูกจัดเก็บในโฟลเดอร์ `public/TilePNG/` และเรียกใช้ไลบรารีเบื้องหลังผ่าน Leaflet ทับลงไปบนแผนที่ฐาน (Base map) อีกที

### 2. ข้อมูลเชิงพื้นที่และค่าสถิติอาคารแบบเจาะจง (GeoJSON)
- **การวิเคราะห์**: นำข้อมูลและรูปทรงหลังคาอาคารแต่ละหลัง (Building Footprints) มาคำนวณซ้อนทับเพื่อประเมินร่วมกันกับผลลัพธ์ของรังสีดวงอาทิตย์ ทำให้ได้ข้อมูลเชิงลึกในแต่ละชั้นข้อมูลและถูกส่งออก (Export) เป็นมาตรฐานไฟล์ที่อ่านข้อมูลได้ง่ายอย่างไฟล์ `.geojson` (ชื่อไฟล์ `BuildingNKK_SR.geojson`)
- **การแปลงข้อมูลลงเว็บ**: ข้อมูลในตารางรายละเอียด (Attribute) ของ GeoJSON จะแนบค่าตัวถูกคำนวณมาด้วย เช่น:
   - พื้นที่หลังคาที่รับแสงได้ (ตร.ม.)
   - รังสีดวงอาทิตย์รวม (MWh/yr)
   - ศัยภาพและประสิทธิภาพการผลิตพลังงานไฟฟ้าขั้นต่ำ (MWh/yr)
   - ความคุ้มค่า / มูลค่าการประหยัดค่าไฟต่อปี
   
เมื่อผู้ใช้งานปักหมุดหรือคลุมคลิกที่โพลิกอนรูปร่างอาคารบนแผนที่ โปรแกรมจำดึงข้อมูล Attribute ของอาคารหลังนั้นจากไฟล์ GeoJSON มาคำนวณและแสดงผลในบัตรข้อมูลด้านข้างให้รับรู้ทันที

## ✨ ฟีเจอร์หลักบนหน้าเว็บไซต์ (Key Features)
- 🗺️ **Interactive Map**: แสดงผลวิเคราะห์ผ่านแผนที่เชิงตอบโต้ (สลับได้ทั้ง ภาพดาวเทียม และแผนที่ภูมิประเทศแบบมืด) พร้อมปุ่มปรับชั้นความเหมาะสม (Filter)
- 🏢 **Clickable Building Insights**: ดึงข้อมูลศักยภาพทางด้านพลังงานรายอาคารที่ประเมินจากซอฟต์แวร์ GIS มาแสดงแบบ Real-time
- 📊 **Statistics Dashboard**: นำตัวเลขภาพรวมการวิเคราะห์ทั้งเมืองมาทำสรุป (เช่น ปริมาณความเหมาะสมในการผลิตไฟฟ้ารวม, จำนวนอาคาร, สัดส่วนความเหมาะสม) 
- 🎨 **Modern Design**: ออกแบบในรูปแบบโทนหน้าจอมืด (Dark Mode) ดูทันสมัยเพื่อให้ข้อมูลจากแผนที่มีความโดดเด่นสะดุดตา

## 🛠️ โครงสร้างเทคโนโลยีที่ใช้พัฒนาหน้าเว็บ (Frontend Tech Stack)
- **React 19** ควบคุมและสร้างโครงสร้างแอปพลิเคชันรูปแบบเว็บไซต์หน้าเดียว (SPA)
- **Leaflet & React-Leaflet** เครื่องยนต์จัดการระบบการแสดงผลแผนที่ (Map Engine)
- **Vite** ประมวลผลและรวบรวมโปรเจกต์
- **Tailwind CSS v4** ทำการจัดสไตล์และปรับความสวยงามทั้งหมดในระบบ

## 🚀 การรันโปรเจกต์ (Local Development)

1. ตรวจสอบว่าในเครื่องมี **Node.js** (เวอร์ชัน 18 ขึ้นไป)
2. ติดตั้งแพ็กเกจ (Dependencies):
   ```bash
   npm install
   ```
3. เริ่มต้นเซิร์ฟเวอร์แบบนักพัฒนา (Development Server):
   ```bash
   npm run dev
   ```
4. ชมผลงานได้โดยเปิดเบราว์เซอร์ไปที่ `http://localhost:5173`
